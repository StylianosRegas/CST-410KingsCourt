# Build 9: component checklist

One row per physical component in the box: how many there are, and the Unity asset, prefab, or data collection that stands for it. Every row is either **Built** or **Out of scope** with a one-line reason, so a gap is visible here and is not found later.

> **Provisional.** The counts and the list below come from the finished rules engine (`Assets/Scripts/Core`, regenerated any time with `RulesSim manifest`) and from the Game Design Document's component list (Part 1). They have not yet been compared against the physical box. The comparison is the parity check in `BUILD9_PARITY_CHECK.md`, and any row that differs from the box gets corrected there.

## Known gaps

- None of the components above is missing from the project.
- The Game Design Document (Part 1) lists 7 chairs, 8 loyalty cards and 50 action cards. The finished rules support 10 seats, 13 roles and a 45-card deck. The box is the source of truth, so these three numbers are the first things to confirm against it (see the parity check).
